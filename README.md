# Flatland Diffusion Model

A simple diffusion model for fixed-length bitstrings, inspired by Edwin A. Abbott's novel "Flatland" where images are represented as one-dimensional sequences.

## Overview

This project demonstrates a complete diffusion model implementation that works with discrete binary data (bitstrings) by operating in continuous space. It illustrates key concepts from modern generative AI including:

- **Forward diffusion process**: Gradually adding Gaussian noise to data
- **Reverse diffusion process**: Removing noise to generate new samples
- **Stochastic Differential Equations (SDEs)**: Mathematical foundation of diffusion models

## Mathematical Foundation

### Forward Process (Noising)

The forward diffusion follows a stochastic differential equation:

```
dx_t = -½β(t)x_t dt + √β(t) dW_t
```

Where:
- `x_t`: Data at time t
- `β(t)`: Variance schedule (controls noise addition rate)
- `W_t`: Wiener process (Brownian motion)
- `dt`: Infinitesimal time increment

This has a closed-form solution allowing direct sampling:

```
x_t = √ᾱ_t * x_0 + √(1-ᾱ_t) * ε
```

Where `ᾱ_t = ∏_{s=1}^t (1-β_s)` and `ε ~ N(0,I)`.

### Reverse Process (Denoising)

The reverse process follows the reverse-time SDE:

```
dx_t = [½β(t)x_t + β(t)∇_x log p_t(x)] dt + √β(t) dW̃_t
```

The score function `∇_x log p_t(x)` guides the denoising. In practice, neural networks learn this score (or equivalently, predict the noise).

## Key Features

## Code Structure

### `FlatlandDiffusionModel` Class

Main class implementing the diffusion model:

- `forward_diffusion_step()`: Single step of noise addition
- `forward_diffusion_direct()`: Direct sampling at any timestep using analytical solution
- `reverse_diffusion_step()`: Single denoising step
- `sample()`: Generate new bitstrings from noise
- `demonstrate_forward_process()`: Visualize the noising process

### Visualization

The `visualize_diffusion_process()` function creates a three-panel plot:

1. **Forward Process (Discrete)**: Bitstrings at different noise levels
2. **Forward Process (Continuous)**: Continuous representation showing SDE solution
3. **Reverse Process**: Denoising trajectory following reverse SDE

## How It Works

### 1. Bitstring to Continuous Mapping

Bitstrings are mapped to continuous space for diffusion:
- `0 → -1`
- `1 → +1`

This symmetric mapping around zero is ideal for Gaussian noise addition.

### 2. Forward Diffusion

Starting from a clean bitstring, Gaussian noise is progressively added according to the forward SDE. The noise schedule `β(t)` controls how quickly information is destroyed.

### 3. Reverse Diffusion

Starting from pure noise, the reverse process gradually removes noise. In this simple implementation, we use a naive denoising function. In practice, neural networks would be trained to predict the score function.

### 4. Sampling

New samples are generated by:
1. Starting from random Gaussian noise
2. Iteratively denoising through the reverse process
3. Thresholding final continuous values back to bits

## Theoretical Connections

### Variance Schedule

The `β(t)` schedule (variance schedule) controls:
- How quickly information is destroyed in the forward process
- The difficulty of the reverse denoising task
- The quality of generated samples

### Score Function

The score `∇_x log p_t(x)` represents the gradient of the log probability density. It points in the direction that increases probability, guiding denoising toward likely samples.

### Discretization

The continuous-time SDEs are discretized for computational implementation:
- Euler-Maruyama method for the forward SDE
- Ancestral sampling for the reverse SDE

## Limitations

This is a simplified educational implementation:

1. **No Learned Model**: Uses a naive denoising function instead of a neural network
2. **Small Scale**: Designed for short bitstrings (e.g., 32 bits)
3. **Simple Patterns**: Best demonstrates concepts with structured patterns

For production diffusion models (images, audio, etc.), you would:
- Use neural networks (U-Nets) to learn the score function
- Train on large datasets
- Use more sophisticated noise schedules
- Apply to much higher dimensional data
